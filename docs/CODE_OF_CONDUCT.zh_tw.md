# 行為準則

Syncmoney 歡迎不同經驗與背景的人參與技術討論、錯誤回報、文件、測試與程式貢獻。參與過程應保持尊重、實用，並確保參與者安全。

英文原文：[`CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md)

## 預期行為

參與者應：

- 依技術內容本身討論想法與程式；
- 先假設善意，但涉及正確性或安全性的主張仍可要求證據；
- 提供可執行的 review 意見，接受修正時避免人身攻擊；
- 尊重不同經驗程度、語言、時區、無障礙需求與溝通方式；
- 對私密回報、credentials、player data 與其他 confidential material 保密；
- 維護者合理指出某行為具破壞性或不安全時停止該行為；
- 若利益衝突會實質影響技術或 moderation 決策，應揭露相關衝突。

## 不可接受的行為

專案空間中不可接受：

- harassment、威脅、stalking、intimidation 或持續性人身攻擊；
- 針對個人特徵的歧視或貶抑言論；
- 性化語言/影像或不受歡迎的性注意；
- 刻意 outing、doxxing 或公開私人資訊；
- 明知而未經授權公開 credentials、私密漏洞細節或敏感 player/server data；
- spam、反覆離題干擾、冒充他人或刻意破壞協作；
- 對善意提出 conduct/security concern 的人進行報復。

技術意見不合、嚴格 code review、關閉不支援的需求，或要求可重現證據，本身不是 misconduct；前提是聚焦工作並以專業方式溝通。

## 適用範圍

本政策適用於專案控制的空間，包括 repository issue、pull request、review 討論、project community channel 與 project event；也適用於某人明確以 Syncmoney 代表身分出現在其他空間時。

## 回報行為問題

可行時，請透過專案官方社群 <https://official.noie.fun> 私下向維護者回報。不要為了回報而在公開 issue 貼出私人個資。

安全漏洞請依 [`SECURITY.md`](../SECURITY.md) 回報，不要公開 exploit 細節。

請提供相關 link/message、日期、涉及人員與簡潔事件描述；只附上維護者理解事件所必要的私人資訊。

## 執行與處置

維護者可依嚴重程度、脈絡、過往行為與影響採取相稱措施，例如私下警告、移除或編輯 abusive content、限制參與、關閉討論、暫時停權或永久移除專案空間權限。

處理回報時，維護者應避免利益衝突，只與解決事件所必要的人分享內容，重大處置在可行情況下應內部留下紀錄。惡意或不實回報本身也可能視為 conduct issue。

# Syncmoney 1.4.0 穩定版發布執行計畫

**目標：** 發布已驗證的 Syncmoney 1.4.0 穩定 Core 與 Web 版本。
**公開 Core 版本：** core JAR、PlaceholderAPI expansion、plugin metadata、Core tag 與 GitHub release 均使用 `1.4.0`。
**公開 Web 版本：** 使用 `1.4.0`，mirror tag 為 `v1.4.0`，並發布 deterministic source archive。
**內部候選版：** Beta.3 保留為內部靜態候選版。Beta.1 產物與 runtime 報告是歷史證據，不可取代穩定版驗收。

更新：2026-11-07，Asia/Taipei

## 發布順序

1. 將已提交的 Gradle 與 Web package metadata 設為 `1.4.0`；同步 `public/version.json`、內嵌 Web distribution 與 `WebAdminServer.extractIndividualFiles`。更新英文與繁體中文使用者、API、架構、開發者文件及 changelog。
2. 使用發布 toolchain 建置 `Syncmoney-1.4.0.jar` 與相符的 expansion。記錄兩者的 byte 長度與 SHA-256，並一併釘選 acceptance 與 API consumer 產物。
3. 以精確穩定版 Core JAR 執行有界 SYNC 驗收：Minecraft 26.2、26.3 各測 Paper、Folia、Canvas。每個結果均綁定 server JAR hash，matrix 綁定精確的穩定版 Core hash。不可沿用 Beta.1 matrix。
4. 驗證候選版、runtime 與 artifact pins。將審核完成的變更推送至 PR #41，並等待目前 PR head 的所有必要 checks 完成。
5. 目前 checks 與 review 條件通過後，依 repository 僅允許的 squash 方法合併 PR #41。從 `main` dispatch `.github/workflows/release.yml`，版本輸入 `1.4.0`。
6. Workflow 執行發布測試、建置與 checksum 驗證、產生 provenance，接著建立不帶前綴的 `1.4.0` tag 與 GitHub draft。`production-release` 環境審核會保護 Web mirror 同步與公開發布。使用設定的 reviewer gate，不繞過審核。
7. 驗證公開 Core release 與 Web mirror，包括 tag 目標、穩定版 metadata、預期 JAR、`release-manifest.json`、`CHECKSUMS.txt`、attestation、Web source archive 及 checksum。依觀察到的結果更新雙語 readiness。

## 必要證據與豁免

- 穩定版六格 matrix 必須以精確的 `Syncmoney-1.4.0.jar` SHA-256 通過。既有 Beta.1 matrix 僅保留為歷史證據。
- 已接受的 T21 live 情境、候選版綁定的 CMI runtime 重測，以及 PAPI cross-pair runtime 情境仍為 `WAIVED / NOT VERIFIED`。負責人回報的 CMI 人工能力測試已完成；不可再次要求或重測。QuickShop UI 購買為選用且未驗證。
- 發布準備期間保留目前所有開啟的 Dependabot PR。合併後，只關閉可確認已被合併相依性更新取代的 PR。
- 已接受的低嚴重度 build-time `deepmerge@4.3.1` advisory 仍須記錄；Malware alert inventory 維持 `UNKNOWN`。
- 穩定版發布的支援聲明不得超出 runtime 證據記錄的精確 server build 與有界情境。

## 目前狀態

正在更新 release branch 與 PR #41，以支援正式穩定版發布。只有 metadata、精確穩定版 runtime matrix、artifact pins、PR checks 與 provenance workflow 驗證均通過後，才具備建立 tag 的條件。公開發布仍受 `production-release` reviewer gate 保護。

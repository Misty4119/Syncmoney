# Syncmoney 1.4.0 穩定版發布執行計畫

**目標：** 發布已驗證的 Syncmoney 1.4.0 穩定 Core 與 Web 版本。
**公開 Core 版本：** core JAR、PlaceholderAPI expansion、plugin metadata、Core tag 與 GitHub release 均使用 `1.4.0`。
**公開 Web 版本：** 使用 `1.4.0`，mirror tag 為 `v1.4.0`，並發布 deterministic source archive。
**內部候選版：** Beta.3 保留為內部靜態候選版。Beta.1 產物與 runtime 報告是歷史證據，不可取代穩定版驗收。

更新：2026-11-07，Asia/Taipei

## 發布順序

1. 將 Gradle 與 Web package metadata 設為 `1.4.0`；同步 `public/version.json`、embedded Web distribution 與 `WebAdminServer.extractIndividualFiles`。更新中英文使用者、API、架構、開發者文件與 changelog。**已在 release source commit `1993e93` 本機完成。**
2. 以發布 toolchain 建置 `Syncmoney-1.4.0.jar` 與相符 expansion，並 pin byte 長度、SHA-256、acceptance 與 API consumer 產物。**已在本機完成**；四個 artifact hashes 已記錄於 `1.4.0-artifact-pins.json`。
3. 以精確穩定版 Core JAR 執行 Paper、Folia、Canvas 在 Minecraft 26.2、26.3 的有界 SYNC matrix。**6/6 通過**，綁定 core SHA-256 `824dcaea57319f5188115bd767ea17ef549d7876273c85deb7f4e092a0906001`；詳見 `1.4.0-stable-runtime-matrix.json`。
4. 驗證候選、runtime 與 artifact pins。**本機驗證已通過。**將 release branch 推送到 PR #41，等待目前 head 的所有必要 checks 完成，並確認審查與合併條件。
5. 目前 checks 與 review 條件通過後，依 repository 僅允許的 squash 方法合併 PR #41。從 `main` dispatch `.github/workflows/release.yml`，版本輸入 `1.4.0`。
6. Workflow 執行 release tests、建置、checksum 與 provenance 驗證，之後建立不帶前綴的 `1.4.0` tag 與 GitHub draft。`production-release` 環境審核會保護 Web mirror 同步與公開發布。使用設定的 reviewer gate，不繞過審核。
7. 驗證公開 Core release 與 Web mirror：tag 目標、穩定版 metadata、JAR、`release-manifest.json`、`CHECKSUMS.txt`、attestation、Web source archive 與 checksum。依觀察結果更新雙語 readiness。

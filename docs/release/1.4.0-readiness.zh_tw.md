## 發布界線與後續步驟

本機候選版驗收在上述豁免下通過。`release/1.4.0` branch 已包含 artifact pins 與已提交的 runtime／candidate evidence。PR 審查、必要 checks 與整合進 `main` 尚待完成。對外發布仍需 GitHub 成功完成 build、checksum、attestation 並建立 draft，最後通過受保護的 `preview-release` 環境審核。依本次記錄，尚未建立 Beta.1 tag、上傳 GitHub asset、寫入 Web mirror 或公開發布。

Core tag 與 GitHub prerelease 必須使用 `1.4.0-Beta.1`，Web mirror tag 使用 `v1.4.0-Beta.1`。本次不建立穩定版 `1.4.0`。發布後需核對兩個 release 頁面、tag target、artifact checksum、provenance 與 mirror metadata，再更新本 readiness record。

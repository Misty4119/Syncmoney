本次續行於 2026-11-07 觀察到 Syncmoney 有 1 個開啟的 Dependabot alert：`syncmoney-web/pnpm-lock.yaml` 中開發相依套件 `deepmerge@4.3.1`，嚴重度 low，且尚無上游修補版。Core code scanning 有 0 個開啟 alert；Core repository 未啟用 secret scanning。Web mirror 未啟用 Dependabot alerts，因此無法取得其獨立 alert inventory；canonical Web source 由 Core repository 的 JavaScript/TypeScript CodeQL workflow 掃描。Dependabot PR #42、#43 已合併，確認被取代的 PR 已關閉；在開啟本次 release evidence PR 前的 inventory refresh 中，Core/Web 均沒有開啟 PR。已重查目前 `.gitignore` 含 `id_ecdsa`、`id_dsa` 與 `*.ppk` 規則。Malware-alert inventory 維持 `UNKNOWN`。

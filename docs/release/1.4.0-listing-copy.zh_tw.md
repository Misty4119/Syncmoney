# Syncmoney 1.4.0 Beta.1 — 平台刊登文案

本內容可用於 SpigotMC 或 Modrinth 專案頁。穩定版 1.4.0 發布前，請保留預覽版標示。

## 簡短描述

相容 Vault 的 Minecraft 經濟插件，支援選用 Redis 跨服餘額、SQL 持久化、交易防護、稽核工具與 Web Admin 儀表板。

## 完整描述

Syncmoney 為 Paper 相容的 Minecraft 網路提供 Vault 相容經濟系統。可選擇單機 SQLite、Redis 共享餘額，或 Redis Pub/Sub 搭配中央 SQL 持久化。VaultUnlocked、PlaceholderAPI 與 Web Admin 為選用整合。若使用 CMI 作為經濟權威，Syncmoney 也可透過 Redis 在多個伺服器間鏡像遊戲幣更新。

Syncmoney 管理玩家餘額與自身經濟指令，不會同步任意權限或第三方指令，也不會自動切換正式網路的經濟權威。

### 功能

- 本機 SQLite、Redis 共享餘額，或 Redis 加上 MySQL、MariaDB、PostgreSQL。
- 在 Syncmoney 管理經濟的模式中支援 Vault 與 VaultUnlocked 互通。
- CMI 僅同步模式由 CMI 維持經濟權威。
- Syncmoney 管理經濟模式提供餘額、轉帳、排行榜與管理指令。
- 交易防護、稽核歷程、選用斷路器與玩家保護。
- 佇列轉帳結果不明時會隔離，並僅接受完全相符的操作收據進行復原對帳。
- 選用 PlaceholderAPI 擴充模組與內嵌 Web Admin 儀表板。
- Paper、Folia 與 Canvas 的 Minecraft 26.2–26.3 是 1.4.0 目標；實測 build 與情境界線列於發布準備紀錄。

### 需求

- 1.4.0 預覽版需要 Java 25 以上。
- Minecraft 26.2–26.3 的 Paper、Folia 或 Canvas；不支援 Plain Spigot。
- local_redis、sync 與 cmi 模式需要 Redis。
- sync 模式需要 MySQL、MariaDB 或 PostgreSQL；local 模式使用 SQLite。
- cmi 模式需要 CMI 與 CMILib。Vault、VaultUnlocked 與 PlaceholderAPI 為選用整合。

### 安裝

1. 備份伺服器插件設定、經濟資料庫與 Redis 持久化資料。
2. 安裝 Syncmoney Beta.1 JAR 與所選經濟模式需要的依賴。
3. 啟動一次產生設定檔，再替該節點設定唯一且非空白的 server-name。
4. 明確選擇經濟模式，只設定該模式需要的服務。
5. 開放交易前確認經濟權威與儲存服務正常。

單一伺服器使用 local。僅需 Redis 而不需要共享 SQL 時使用 local_redis。需要 Redis 與中央 SQL 時使用 sync。只有在必須由 CMI 維持經濟權威時使用 cmi。CMI 僅同步模式不會註冊 Syncmoney Vault provider 或公開經濟 API，也不提供 Syncmoney 經濟佔位符。

既有網路切換至 local_redis 或 sync 前，請先檢查 Redis 餘額是否超過共享模式上限 999999999999999999.99。Syncmoney 1.4.0 不會自動截斷或遷移超出上限的既有餘額。

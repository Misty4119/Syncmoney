## Release acceptance criteria

The Beta.1 prerelease is ready only when:

1. The reviewed release PR is merged under the active `main` protection and all
   required status checks pass.
2. All mandatory test/runtime gates have current evidence; owner-approved
   waivers remain explicitly labeled and any non-waived mandatory gate that is
   still `NOT VERIFIED` blocks publication.
3. The final Beta.1 source manifest pins the exact release artifacts and has no
   unreviewed source or Git-status mismatches.
4. Full dependency-audit output, the accepted #105 residual risk, and
   `Malware alerts: UNKNOWN` are recorded without claiming a clean complete
   audit or a zero malware-alert count.
5. The protected preview environment approves publication, the GitHub release
   and Web mirror identify the same Beta.1 version, and every uploaded checksum
   matches the final artifacts.

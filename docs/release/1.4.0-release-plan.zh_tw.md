# Syncmoney 1.4.0 Beta.1 發布執行計畫

**狀態：** 本機 Beta.1 候選版與 runtime gate 在已接受豁免下通過。來源、文件、`.gitignore` 與 release workflow 準備已完成；PR 整合與受保護發布仍待完成。
**來源狀態：** 目前的 1.4.0 程式碼已以 Beta.3 驗收
**對外版本：** `1.4.0-Beta.1`
**發布通路：** GitHub 預覽版與官方 Web mirror
**穩定版 1.4.0：** 不包含在本次發布；須另行通過穩定版 gate。

更新日期：2026-11-07（Asia/Taipei）

## 已驗證進度

- 精確的本機 Beta.1 JAR 已通過完整 Java／PAPI／API／package build，以及 Minecraft 26.2、26.3 的 Paper／Folia／Canvas 六個有界 runtime 情境。精確 pins 與證據範圍記錄於[發布準備紀錄](1.4.0-readiness.zh_tw.md)。
- 負責人接受的 T21、CMI 與 PAPI cross-pair 豁免仍標示 `WAIVED / NOT VERIFIED`，不會報成通過。QuickShop UI 尚未驗證，但屬選用項目。
- Release workflow 會先完成 build、checksum、provenance，再建立 draft。GitHub `main` 保護規則與 `preview-release` 必需審核者已設定；截至 2026-11-07，GitHub 有 17 個 Dependabot alerts、13 個開啟的 Dependabot PR，Malware alerts 為 `UNKNOWN`。
- Source branch 已包含 Beta.1 artifact pins 與已提交的 runtime／candidate evidence；仍需審查 PR、通過必要 checks 並合併。之後受保護的 release workflow 必須重建、核對 checksum、attestation 並建立 draft，才由負責人核准 preview 發布。尚未建立 tag、上傳 release assets、寫入 Web mirror 或公開發布。

本文件記錄發布決策與剩餘工作。現有
`Syncmoney-1.4.0-Beta.3.jar` 及其證據會保留為內部候選。對外產物會以相同

## 發布驗收條件

Beta.1 prerelease 僅在以下條件成立時可發布：

1. 已透過現有 `main` 保護合併 release PR，且全部必需 status checks 通過。
2. 所有必要測試／runtime gate 都有最新證據；負責人同意的豁免維持明確標示，任何仍為
   `NOT VERIFIED` 且未豁免的必要 gate 都會阻止發布。
3. 最終 Beta.1 source manifest 綁定精確發布產物，且沒有未審查的來源或 Git status mismatch。
4. 記錄完整 dependency audit、已接受的 #105 殘餘風險與 `Malware alerts: UNKNOWN`；不宣稱
   完整 audit 乾淨或 malware alert 數為零。
5. 受保護的 preview environment 核准發布，GitHub release 與 Web mirror 使用相同 Beta.1
   版本，且每個上傳 checksum 都符合最終產物。
